# Run the tests without fixing them

Run the test suite for this project using pytest.

Do not modify any source files, test files, configuration files, dependencies, or other files in the workspace. Do not fix failing tests or change the code. Do not create or delete files.

After the test run completes, report only:

- The command you ran.
- Whether the test suite passed or failed.
- The number of passed, failed, skipped, and errored tests.
- For each failure or error, provide the test name and a concise failure summary.

If tests fail, report the failures without attempting to fix them. If the test command cannot run, report the command and the blocking error.
